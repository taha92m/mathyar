روش قرار دادن روی GitHub Pages (رایگان و HTTPS):
1. یک مخزن جدید در GitHub بساز (مثلاً mathyar).
2. فایلهای بالا را آپلود کن.
3. برو به Settings > Pages.
4. Source را روی Deploy from a branch بگذار، Branch را main و پوشه را /(root) انتخاب کن و Save بزن.
5. بعد از یک دقیقه آدرسی به این شکل میدهد:
   https://USERNAME.github.io/mathyar/
6. همان لینک را در بله بفرست.
7. فایل mathyar-qr.png هم QR کد همان لینک است؛ آن را هم میتوانی در بله بفرستی.

روی گوشی اندروید:
- داخل صفحه، دکمه «📲 نصب اپ ریاضیار» ظاهر میشود؛ با زدن آن اپ نصب میشود.
- اگر دکمه ظاهر نشد، لینک را در Chrome باز کن، منوی سهنقطه > Install app / Add to Home screen را بزن.
- برخی نسخههای بله دکمه نصب را نشان نمیدهند؛ استفاده از Chrome مطمئنتر است.
- روی آیفون هم راهنمای «Add to Home Screen» داخل صفحه نمایش داده میشود.

نکته: سرویس ورکر و نصب شدن فقط روی HTTPS (یا localhost) کار میکند.
آدرس محلی http://192.168.1.199:8000 فقط برای تست داخل همان وایفای است.

پنل معلم و مدیر:
- از پایین فرم صفحه، دکمه «👩‍🏫 پنل معلم و مدیر» را بزن.
- رمز پیشفرض: 1234 (قابل تغییر از داخل پنل).
- در پنل: تعداد تستها، تعداد پاسخ درست و نادرست، میانگین نمرات،
  خلاصه هر دانشآموز، لیست تمام تستها و خروجی CSV برای اکسل دیده میشود.
- فیلتر بر اساس دانشآموز، کلاس، سختی و فصل هم وجود دارد.
- نکته: آمار فقط روی همان گوشی/مرورگری که تست زده شده ذخیره میشود؛
  برای آمار متمرکز تمام دانشآموزان به سرور نیاز است.
